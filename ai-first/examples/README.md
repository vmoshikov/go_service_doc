# Пример сгенерированной wiki

`wiki-sample/` создали генераторы на тестовых репозиториях. Ничего здесь не написано вручную.

- `code/etcd-backup/` — компонент: gRPC с HTTP-привязкой, CRD, метрики, CHANGELOG трёх тегов (`code_docs.py` на каждый тег).
- `code/api-gateway/` — минимальный компонент.
- `code/core/` — общий модуль: два компонента используют разные версии.
- `code/releases/` — три релиза платформы. Ссылки «коммит …» ведут на документацию той версии, что была в релизе.
- `changes/MK8S-101.md` — страница изменения для QA (`changes_sync.py`).

Начни с `wiki-sample/index.md` и `wiki-sample/code/releases/2026.10.1.md`.
