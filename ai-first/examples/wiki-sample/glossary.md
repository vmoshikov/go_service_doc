# Глоссарий

Один термин — одно значение. Добавляй термин при первом использовании в wiki.

| Термин | Значение |
|--------|----------|
| L2 | Документация линии поддержки. Источник — Confluence. Папка `wiki/l2/`. |
| L3 | Документация для клиентов платформы. Источник — Confluence. Папка `wiki/l3/`. |
| Code | Документация кода. Создаёт генератор. Папка `wiki/code/`. |
| Компонент | Часть платформы со своим образом и своим чартом. Описан в `wiki/code/components.toml`. |
| Общий модуль | Go-модуль, который импортируют компоненты. Отдельно не разворачивается. |
| Релиз платформы | Тег репозитория чартов. Задаёт версии чартов и теги образов всех компонентов. |
| Образ платформы | Сборка в Nexus по тегу репозитория чартов. |
| Runbook | Пошаговая процедура для дежурного: симптомы, диагностика, действия, эскалация. |
| ADR | Architecture Decision Record — запись архитектурного решения. Хранится в `docs/` репозитория компонента. |
