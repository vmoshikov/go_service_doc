# wiki-index

Скил создаёт `wiki/index.md`. Не редактируй этот файл вручную.

## Запуск

```bash
python scripts/wiki_index.py
python scripts/wiki_index.py --check   # для CI
```

## Результат

`wiki/index.md` содержит:

1. Компоненты: версия документации, число страниц L2 и L3, ссылки на страницы Code. «—» в L2 или L3 — пробел в документации поддержки.
2. Общие модули.
3. Релизы платформы, новые сверху.
4. Списки страниц L2 и L3 с компонентами.

`--check`: код 1, если `index.md` устарел.
