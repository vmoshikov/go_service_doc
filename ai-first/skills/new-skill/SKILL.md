# new-skill

Скил создаёт заготовку нового скила. Каждый скил состоит из двух файлов:

- `skills/<имя>/SKILL.md` — когда использовать скил и как его запустить;
- `scripts/<имя>.py` — реализация на Python.

## Запуск

```bash
python scripts/new_skill.py export-report "Используй, когда нужен отчёт по продажам в CSV."
```

Имя пиши в kebab-case. Скрипт получает имя в snake_case: `export_report.py`.

## После запуска

1. Реализуй логику в `scripts/<имя>.py`. Используй `argparse` для параметров.
2. Заполни раздел «Результат» в `SKILL.md`.
3. Запусти проверку: `python scripts/check_skills.py`.

## Правила для скрипта

- Только стандартная библиотека Python, если задача не требует другого.
- Код возврата 0 — успех. Код 1 — ошибка.
- Сообщения об ошибках выводи в stderr.
- Пути считай от корня репозитория: `Path(__file__).resolve().parent.parent`.
- Соблюдай `rules/pii.md`: скрипт не выводит ПДн и секреты.
