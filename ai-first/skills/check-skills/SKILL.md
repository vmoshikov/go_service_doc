# check-skills

Скил проверяет связь между `skills/` и `scripts/`.

## Запуск

```bash
python scripts/check_skills.py
```

## Что проверяет скрипт

1. В каждой папке `skills/<имя>/` есть `SKILL.md`.
2. Во frontmatter есть поля `name` и `description`.
3. Поле `name` совпадает с именем папки.
4. Для скила `<имя>` есть `scripts/<имя_в_snake_case>.py`.
5. Для каждого `scripts/*.py` есть скил.

Общие модули называй с префиксом `_`, например `scripts/_paths.py`. Скрипт их не проверяет.

## Результат

Код 0 — ошибок нет. Код 1 — скрипт выводит список ошибок.
