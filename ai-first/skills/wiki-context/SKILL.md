# wiki-context

Скил находит страницы wiki, которые нужно прочитать до изменения кода.

## Запуск

```bash
python scripts/wiki_context.py --here retention
python scripts/wiki_context.py -c etcd-backup s3
python scripts/wiki_context.py --section l2 кворум
```

Из репозитория компонента: `python .wiki/scripts/wiki_context.py --here <слова>`.

| Параметр | Значение |
|----------|----------|
| `слова` | ключевые слова задачи |
| `-c` | компонент или модуль; можно повторять |
| `--here` | компонент текущего git-репозитория по реестру |
| `--section` | только `l2`, `l3` или `code` |
| `--limit` | число строк, по умолчанию 15 |

## Результат

Строки: оценка, тип страницы, путь, заголовок. Читай страницы с наибольшей оценкой первыми.

Если страниц нет, прочитай `wiki/index.md`.
