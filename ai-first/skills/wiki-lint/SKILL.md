# wiki-lint

## Запуск

```bash
python scripts/wiki_lint.py
```

## Что проверяет скрипт

| Проверка | Уровень |
|----------|---------|
| L2/L3: поля `title`, `url`, `synced`; дата в формате ГГГГ-ММ-ДД | ошибка |
| L2/L3: нет компонентов или компонента нет в реестре | внимание |
| L3 ссылается за пределы `l3/` | ошибка |
| внутренний IP-адрес в L3 | внимание |
| в `code/` страница без `generated: true` (кроме `docs/` команды) | ошибка |
| битые локальные ссылки | ошибка |
| секреты во всех `.md` внутри `wiki/`, включая `raw/` | ошибка |
| реестр: нет `repo`, `chart`, `module` или `owner` | ошибка |
| каталог в `code/` без записи в реестре | внимание |

Для секрета скрипт выводит файл и строку. Значение скрипт не выводит.

## Результат

Код 0 — ошибок нет. Код 1 — есть ошибки.
